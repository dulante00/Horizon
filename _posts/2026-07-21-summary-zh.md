## [HuggingFace 发布 Grabette：机器人操作数据采集开源系统](https://huggingface.co/blog/grabette) ⭐️ 7.0/10

HuggingFace 推出了 Grabette，这是一个用于标准化机器人操作数据采集与共享的开源系统。该工具旨在通过在不同硬件平台之间提供统一的数据格式，解决机器人学习中的数据集碎片化问题。 高质量、标准化的示教数据是机器人模仿学习和策略训练的关键瓶颈，而该领域一直面临着不同机器人平台之间数据格式不兼容的问题。通过提供一个开放的统一流程，Grabette 可以降低研究者在数据贡献和共享方面的门槛，推动机器人学习的发展，就像 ImageNet 曾推动计算机视觉进步一样。 Grabette 被定位为 HuggingFace 更广泛机器人生态系统的一部分，与其现有的 LeRobot 框架互补。该系统强调跨硬件兼容性，允许从不同机械臂和传感器采集的数据以一致的格式存储，适用于下游模仿学习流程。

rss · HuggingFace Blog · 7月21日 00:00

**背景**: 机器人模仿学习通过让机器人学习人类示教来执行任务，类似于大型语言模型从文本语料库中学习的方式。然而，与可以轻松在线共享的文本或图像数据不同，机器人操作数据具有硬件特异性，采集成本高昂，并且通常与特定的机器人型号绑定。这种碎片化使得构建大规模、多样化的数据集变得困难。Grabette、LeRobot 和 MimicLabs 等开源框架旨在通过提供跨不同机器人平台工作的标准化采集工具和数据格式来解决这个问题。

## [Jack Dorsey 推出 Buzz：基于 Nostr 协议的聊天、智能体与 Git 一体化工作空间](https://runtimewire.com/article/jack-dorsey-block-buzz-team-chat-ai-agents-git) ⭐️ 6.0/10

Jack Dorsey 创立的 Block 公司推出了 Buzz，这是一款开源且可自托管的工作空间工具，集成了团队聊天、AI 智能体（agents）和 Git 托管，并使用经过签名的 Nostr 事件作为底层数据层，以便团队保留对自身数据的控制权。 此次发布表明一位极具影响力的创始人正在押注于去中心化、加密签名的协议（Nostr）作为企业协作工具的基础，直接挑战 Slack 和 Teams 等现有巨头。它也反映了将 AI 智能体嵌入日常开发者工作流程的更大趋势，并引发了关于数据所有权和智能体权限的诸多问题。 Buzz 依赖经过签名的 Nostr 事件进行所有通信，这意味着身份与加密密钥绑定，数据可在各个中继（relay）之间移植；该项目是开源且自托管的，意味着团队必须自行运维基础设施。社区评论者注意到其宣传网站使用大量 JavaScript，并质疑一个面向社交场景设计的协议是否适合用于企业级、多用户 AI 智能体场景下的访问控制。

## [提示缓存 + 粘性路由：如何降低 LLM API 成本](https://openrouter.ai/blog/tutorials/prompt-caching-sticky-routing/) ⭐️ 6.0/10

OpenRouter 发布了一篇教程，解释了提示缓存和粘性路由如何协同工作以降低 LLM API 成本。该指南指出，缓存读取的成本仅为新鲜输入 token 的 0.1 倍到 0.5 倍，但前提是后续请求被路由到持有热缓存的同一提供商。 这对大规模构建 LLM 应用的工程师至关重要，因为每轮对话中重复出现的系统提示、工具定义和 JSON 模式信息会占据大量 token 成本。如果没有粘性路由，标准负载均衡器可能在不知不觉中将请求分发到不同的提供商，导致缓存失效并悄悄推高账单。 该教程提供了验证缓存确实生效的具体方法，包括检查响应元数据字段如 cached_tokens。粘性路由确保共享同一标识符（例如会话 ID）的请求始终被路由到同一后端，从而在多轮对话中保留 KV/prefill 缓存。

rss · OpenRouter Blog · 7月21日 00:00

**背景**: 提示缓存是一种技术，LLM 提供商会存储最近处理过的提示前缀，并复用已计算的注意力状态（KV 缓存）来处理后续请求，从而显著降低延迟和成本。标准负载均衡器会将请求分发到多个后端服务器或提供商以提高可靠性，但这可能会分散缓存。粘性（或会话保持）路由确保共享标识符的请求始终被发送到同一后端，从而保持缓存热度。过去一年 LLM API 价格下降了约 80%，提示缓存已成为进一步降低成本的关键手段，一些提供商提供的缓存读取价格为正常输入价格的 10%-50%。
